# 🌌 Aether — Next-Gen SaaS Landing Page Template

A modern, high-converting single-page SaaS startup landing page built with **React 18**, **Tailwind CSS**, **Framer Motion**, and **Lucide React**.

---

## ✨ Features & Capabilities

- ⚡ **Frictionless Velocity Aesthetic**: Deep-space dark theme (`#06080F`), vibrant glowing accents, glassmorphic panels (`backdrop-blur-xl`), and ambient floating gradient orbs.
- 🎨 **Multi-Theme Engine**: Real-time theme switcher with 4 curated palettes (**Deep Nebula**, **Clean Light**, **Cyber Emerald**, and **Cosmic Sunset**).
- 🛸 **Continuous Floating Physics**: Layered 3D glass dashboard with animated floating badges ("Global Latency 1.8ms", "Canary Pass +99.4%", "Zero Downtime Deploy").
- 🧩 **Asymmetric Bento Grid**: 6 high-tech feature cards with hover-lift micro-interactions, custom SVGs, and real-time node connection indicators.
- 💻 **Interactive Multi-Language Code Editor**: Switch between **TypeScript**, **Python**, and **Go** with 1-click syntax copy.
- 🚀 **Interactive CI/CD & Telemetry Simulator**: Live step-by-step canary deployment visualization and real-time streaming telemetry logs.
- 📊 **Dynamic Pricing Calculator**: Monthly & Annual billing switch with automated 20% discount calculations and glowing popular tier badge.
- ⭐ **Testimonials Grid**: Verified customer reviews with metrics callouts and star ratings.
- ❓ **Animated FAQ Accordion**: Smooth Framer Motion spring expansion.
- 🎯 **High-Conversion CTA Banner**: Interactive email validation form and risk-free guarantee pills.
- 📱 **100% Mobile Responsive**: Mobile hamburger drawer navigation with spring slide-down animation.

---

## 🛠️ Tech Stack

- **Framework**: React 18+ (Vite)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Visit `http://localhost:3000` in your browser.

### 3. Build for Production
```bash
npm run build
```
