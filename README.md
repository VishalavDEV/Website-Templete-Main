# Asentus — Hi-Tech Modern Architecture & Corporate Web Template

A high-tech, modern web application template featuring a decoupled architecture with a **Spring Boot 3 REST API** backend and a **React 19 + Vite** frontend.

## ??? Features
- **Modern Architectural Aesthetic**: Monochromatic high-tech theme with deep charcoal, crisp white typography, and cyan/teal accents.
- **Hero Slider**: Fullscreen carousel with **HI-TECH DESIGN** typography, auto-transition, slide controls, and CTA links.
- **Core Pillars**: *Art of Coding*, *Responsive Design*, and *Feature Reach* service cards with micro-interactions.
- **Project Showcase**: Interactive filterable architectural portfolio with detailed Case Study modals.
- **Pricing Matrix**: 3-tier pricing matrix with automated contact form integration.
- **Interactive Contact Form**: Real-time form with inline validation connected to Spring Boot backend API.

## ?? Getting Started

### 1. Spring Boot Backend
```bash
cd backend
mvn spring-boot:run
```
Backend runs by default on `http://localhost:8085` (Endpoints: `/api/slides`, `/api/features`, `/api/products`, `/api/pricing`, `/api/faq`, `/api/contact`).

### 2. React + Vite Frontend
```bash
cd frontend
npm install
npm run dev
```
Frontend runs by default on `http://localhost:5173` (or `http://localhost:5174`).
